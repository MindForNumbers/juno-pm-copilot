## What "good" means

>=85% Jira push completion rate; <10% manual PRD copy replacement; 0 hallucinated citations.

- **Active:** PM clicks "Acknowledge Risk" vs "Ignore" on agent cards; explicit error flags on Jira export; manual inline edits to generated PRD markdown.
- **Passive:** Session abandonment rate; latency-to-export time; frequency of PRD rewrites (>25% copy altered).

## The stack

| Layer | Evaluator | What it catches | Threshold / gate |
|---|---|---|---|
| **Layer 1: Component-Level** | Automated CI checks & LLM-as-Judge · Cadence: Every PR + nightly cron · Owner: CI/Eng for schema/latency, PM for strategy alignment. | - Missing verbatim citations (<3 quotes)<br>- Invalid Jira JSON schema<br>- Hallucinated metrics/names<br>- Strategic pillar misalignment | 100% citation string match; 100% schema validation; >=95% strategic alignment score. |
| **Layer 2: System-Level** | Human Evaluation (`06-evals/human-rubric.md`) · 2 Senior PMs + 1 Eng Lead · Cadence: Weekly batch (Friday) | - Subtly incorrect strategic trade-offs<br>- Vague or noisy agent risk warnings<br>- Flawed acceptance criteria logic | >=4.5/5 on Evidence Accuracy; 0 hallucinated quotes; 0 missed P0 tech debt risks. |
| **Layer 3: Online Evals** | Real-time user telemetry & cohort feedback · Cadence: Per session + weekly review · Owner: Lead PM | - Low adoption / abandonment<br>- Repetitive risk overrides (indicates prompt drift)<br>- Post-export Jira ticket edits | >=85% Jira push completion rate; <5% risk-override reversal; <10% manual PRD replacement. |

## Golden set

- 200 multi-source customer payloads (Zendesk P0/P1 tickets + Gong transcripts) paired with gold-standard human-authored PRDs and verified risk flags.
- Versioned in git at `06-evals/golden-set/v1.json`, refreshed quarterly or whenever the Strategy One-Pager updates.

## Release gate

**Hard gates (auto-block):**

- < 3 verifiable customer citations extracted from raw input.
- Any hallucinated customer name or ARR metric.
- Uncaught P0 technical debt warning bypassed without PM acknowledgment.
- Schema parse failure on Jira export payload.

**Soft gates (PM sign-off):**

- p95 execution latency between 12s and 15s requires Lead PM sign-off.
- Citation relevance score between 70% and 79% requires PM rationale override.

**User-feedback layer (online):** Cadence: Real-time per session + weekly cohort aggregation; Lead PM reviews weekly. Automated alert triggered if >=3 Jira export failures occur within 24 hours.
