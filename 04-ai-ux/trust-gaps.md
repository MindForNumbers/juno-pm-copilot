## Trust gaps

| Gap | Where it shows up | User cost | Mitigation |
|---|---|---|---|
| **The Black-box Gap** | Can the user see why the AI decided? | Noticeable but recoverable (5/5 closed) | Surfaces a clean vertical feed of individual "Agent Signals" (e.g., backend risk warnings) alongside the draft. The PRD explicitly cites verbatim customer quotes mapped to strategic pillars so the evidence is highly visible. |
| **The Hallucination Gap** | Could this confidently be wrong? | Noticeable but recoverable (5/5 closed) | Strict Verification Gate: If the AI cannot extract 3 verifiable, verbatim quotes, it halts, displays an "Insufficient Evidence" banner, and permanently disables the "Push to Jira" button. |
| **The Control Gap** | Can the user steer or stop? | Noticeable but recoverable (5/5 closed) | The generated PRD canvas is fully editable text. PMs must manually click "Acknowledge" on individual agent warnings, and the final Jira export is always a deliberate, manual click (Write = Confirm). |
| **The Intelligence Tax** | Is the latency / privacy / cognitive load worth the value? | Noticeable but recoverable (5/5 closed) | Masks the 12s p95 latency with dynamic handshake breadcrumbs ("Synthesizing...", "Running parallel reviews..."). Automatically collapses raw text intakes after processing to radically reduce cognitive load. |

## Highest-priority fix

**The Hallucination Gap** (5/5). 
The highest structural risk for a PM is pushing confidently fabricated requirements to a shared engineering backlog. We closed this by linking the UI state directly to the verification check: if the Synthesizer agent cannot find three verbatim citations, the "Push to Jira" button becomes physically unclickable, forcing human intervention and halting the pipeline.

## Verdict

**Ship.** All trust gaps are actively closed through explicit UI/UX layout decisions and strict architectural constraints.
