## Entry point

**Signal type:** Specific user action (button, selection)

The PM pastes a Zendesk ticket, Gong transcript, or MS Lists export into the Intake Column and clicks the "Process Transcript" button to initiate the multi-agent pipeline.

**What they see instantly**

The button immediately disables and shifts to an active loading state. The Agent Insights Hub resets all cards to an "Idle" status. The first handshake breadcrumb fires: "Synthesizing customer evidence..."

## The flow

1. Synthesizer agent extracts verbatim quotes and Drafter agent creates the initial PRD.
2. Handshake breadcrumb updates to mask latency: "Drafting initial specifications..."
3. Parallel review agents (Lead Eng, PMM, Data Scientist, Scrum Master) execute against the draft.
4. Handshake breadcrumb updates: "Running parallel adversarial reviews..."
5. Column 1 (Context & Intake) automatically collapses the raw text input into a sleek "Active Sources" accordion to remove visual clutter and signal the transition from data to insights.

## AI moments

**Placement:** Hybrid · multiple placements at once

The outputs land concurrently in a dedicated, scannable 3-column review space. Column 1 collapses the raw data. Column 2 (Agent Insights Hub) populates a clean vertical feed of high-contrast agent signals (e.g., Tech Debt warnings). Column 3 (Draft PRD & Delivery) simultaneously renders the fully formatted Markdown specification mapped to strategic pillars.

This maneuver provides pure augmentation while applying the "Iceberg" mental model. By hiding the raw input walls and surfacing only decision-ready risk flags alongside the PRD, we radically lower cognitive load. The UI shifts the PM from a manual builder into a strategic reviewer. The PM retains control by explicitly confirming the action via the "Push to Jira" button.

## Fallbacks

**Kill switch**

The PM can click "Acknowledge" or "Ignore" on any specific agent's risk warning card, or manually edit the text inside the PRD Canvas. The PM can abandon the session entirely; nothing writes to the backlog without explicit confirmation.

**Training signal**

Clicking "Ignore" on an agent risk flag (e.g., overriding the Lead Engineer's latency warning) logs a `risk_overridden` event. If a specific type of risk is overridden five times in a week, that agent's system prompt is routed for human review.

**Fail-safe**

If the Synthesizer agent cannot extract at least 3 verifiable, verbatim quotes from the input, the pipeline halts. The PRD Canvas displays a banner stating: "Insufficient customer evidence to proceed. Strategy requires 3 citations." The "Push to Jira" button remains permanently disabled. Juno never invents a quote to bypass the gate.
