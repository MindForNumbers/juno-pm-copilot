## Autonomy level

Agent squad can draft PRD canvas, score strategic alignment, and surface persona-specific risk flags. Agent CANNOT auto-publish epics to Jira, modify active sprints, or broadcast messages to GTM/sales teams.

## Controls

- **Kill switch:** max_steps: 3 per agent (18 total across squad). Abort if any tool fails 2x in a row. Hard timeout: 15s wall clock.
- **Rate / cost caps:** `extract_transcript_signals` to `{quotes:[{text, source_id, timestamp, relevance_score}], confidence}`. `read_strategy` to `{pillars:[{id, name, text}], match_score}`. Cost ceiling: $0.15 per complete squad execution.
- **Escalate-on-stuck:** If Strategy One-Pager is unreachable, drop to "Quality Mode" (evaluate request quality only, banner output). If < 3 verbatim quotes are extracted, abort PRD generation, display verbatim failure script, and lock Jira export. After 2 tool errors, escalate to PM with full error trace.

## Monitoring

**Confidence thresholds (map to actions):**

Evidence confidence ≥ 80% (with ≥ 3 verbatim quotes) allows PRD generation and Jira staging. 70% to 79% surfaces a visible "Weak Evidence" warning badge and requires PM rationale override. Below 70% (or < 3 quotes) halts drafting, renders "Insufficient Evidence" banner, and locks the "Push to Jira" button.

**Checkpoints:**

Any P0 Technical Debt flag raised by the Lead Engineer agent locks the "Push to Jira" export until the PM explicitly clicks "Acknowledge Risk". Any contradiction between strategic pillars routes to the PM for human tiebreak.

**North Star (re-read every loop):**

You are Juno. Your single goal is to synthesize customer signals into evidence-backed PRD drafts evaluated by a 6-agent review squad, never hallucinating customer citations or bypassing technical debt gates.

## Permissions

READ: Git Strategy One-Pager, Zendesk P0/P1 tickets (90d), Gong transcripts (90d). WRITE: Local PRD canvas and Jira backlog epics only. CANNOT access executive Slack DMs, edit active sprint boards, or broadcast externally.
