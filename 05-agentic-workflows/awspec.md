## Goal

Ingest raw customer signals, draft a specification, and execute a parallel 6-agent adversarial review to ensure evidence-backed prioritization before Jira export (Augmentation).

**Primary actor:** Planner + Executor agents (with Human-in-the-loop)

## Trigger

The PM pastes a Zendesk ticket, Gong transcript, or MS Lists export into the Intake Column and manually clicks the "Process Transcript" button.

## Steps & tools

**Pattern:** Planner-Executor (multi-agent, parallel)

| Step | Action | Tool / model | Guardrail |
|---|---|---|---|
| 1 | Extract verbatim quotes & read strategy. | `extract_transcript_signals(payload)`, read-only | Halts pipeline if < 3 verifiable quotes are found. |
| 2 | Draft initial PRD canvas. | `draft_prd_canvas(quotes, strategy)`, draft | Must map directly to retrieved strategic pillars. |
| 3 | Execute parallel adversarial reviews (6 agents). | `run_adversarial_agent_review(draft)`, draft | 3-turn limit per agent to prevent infinite loops. |
| 4 | Present flags & wait for human review. | N/A (UI layer) | "Push to Jira" button physically disabled if P0 risks are present. |
| 5 | Export prioritized epic to backlog. | `push_epic_to_jira(epic_data)`, write, confirm | Requires explicit PM click; cannot auto-export. |

**Schemas**

- `extract_transcript_signals` → `{quotes:[{text, source_id, timestamp}]}`
- `draft_prd_canvas` → `{markdown_body, mapped_pillars}`
- `run_adversarial_agent_review` → `{persona, risk_flag_boolean, warning_text}`
- `push_epic_to_jira` → `{epic_id, url, status}`

**Memory (in or out of scope)**

- **Episodic:** In-scope, tool results, extracted quotes, generated PRD draft, agent risk flags. Lifetime: end of session/browser refresh.
- **Semantic:** In-scope, PM overrides on specific risk flags (e.g., accepting Tech Debt). Lifetime: 90 days. Out of scope, do NOT persist insights or feature priorities across different PM accounts.
- **Working:** In-scope, current loaded transcript, retrieved Git strategy chunks. Held in working context only.
- **External:** Zendesk/Gong APIs (read), Git repository Strategy KB (read), Jira (write, backlog creation only).

## Human-in-the-loop

PM reviews the drafted PRD and the Agent Insights Hub concurrently. The PM must manually click "Acknowledge" on any severe risk flags (like a Lead Engineer Tech Debt warning) before the system enables the "Push to Jira" button. Final export is always a deliberate manual click.

## Success & failure

- **Done when:** 
  - Success: Fully reviewed PRD epic is successfully pushed to the Jira backlog.
  - Failure: Synthesizer extracts < 3 verifiable quotes → halt, label "Insufficient Evidence", and permanently disable export.
  - Escalation: Lead Engineer agent flags a P0 Tech Debt risk OR retrieved strategy contradicts itself → hand to PM for explicit override.
  - Timeout: 15s wall clock (exceeding p95 12s budget) → abort with partial output (e.g., "Manual telemetry definition required").
- **Fails safe when:** Agent can READ Zendesk/Gong transcripts and Git strategy. Agent can DRAFT PRD canvas and risk flags locally. Agent CANNOT write to Jira without human confirmation. Agent CANNOT modify active sprints, broadcast to Slack, or email Go-To-Market teams.
