## 01 Context · Data Requirements

**Required sources, and exclusions**

Required: RocketShip Strategy One-Pager (pulled live from the Git repository), Zendesk P0/P1 support tickets from the last 90 days, and Gong sales/support transcripts from the last 90 days.
Excluded: Salesforce closed-lost notes and executive Slack DMs. Both are opinion-heavy or financially biased, allowing the model to rank features based on seniority or panic rather than empirical user evidence. Scoping strictly to support and transcripts prevents cross-contamination of executive opinions.

**SLA of truth**

Strategy One-Pager: Re-syncs on commit. Zendesk and Gong: Hourly sync.
If the Strategy document is unreachable, Juno does not proceed on cached or hallucinated strategy. It halts Strategy Mode, routes to "Quality Mode," and explicitly banners the output: "Without strategy document, priority reflects request quality, not strategic alignment."

## 02 Tools · System Capabilities

**The verb list**

read_strategy(doc_id) - READ

extract_transcript_signals(source_id) - READ

draft_prd_canvas(quotes, strategy) - DRAFT

run_adversarial_agent_review(draft, persona) - DRAFT

push_epic_to_jira(epic_data) - WRITE

**Deliberate omissions**

No create_jira_sprint() or modify_active_sprint(). Moving live engineering tickets is class WRITE and disrupts developer workflows unpredictably. Juno strictly queues prioritized drafts for the backlog.
No notify_slack_channel(). Broadcasting a draft based on AI prioritization is a class SEND action. Promising an unvetted feature to the Go-To-Market team creates irreversible external commitments.

## 03 Loop · AI Costs & Latency

**Turn ceiling and escalation**

Ceiling of 3 turns per agent. On turn 3, if an agent cannot complete its task (e.g., the Data Scientist agent cannot define telemetry), it returns its best attempt labeled "Manual definition required."
Escalate to the PM immediately if the Lead Engineer agent flags a P0 technical debt violation, or if retrieved clauses from the Strategy One-Pager directly contradict each other.

**Latency and cost target**

p95 under 12 seconds from the "Process Transcript" click to the fully rendered 3-column dashboard, executing the parallel agent review. Cost ceiling is $0.15 per multi-agent run.

## 04 Memory · Data Requirements

**What persists, at what scope**

Per PM, per session. The extracted insights, anti-pattern flags, and risk assessments generated by the 6-agent squad persist only for that active browser session. Insights and feature priorities do not cross-contaminate between different PMs or product teams.

**Expiry and write rules**

Session data clears on a hard refresh or when a new transcript is loaded into the intake column. A human PM's explicit override (e.g., clicking "Accept Technical Debt Risk") is written to the database and persists for 90 days. Human overrides strictly outrank model-generated warnings on all future runs.

## 05 Permissions · AI Risks & Mitigations

**The autonomy dial**

| Side-effect class | Tier |
|---|---|
| read | auto |
| draft | auto |
| write | confirm |
| send | blocked |

**Justification**

Reads are auto because the blast radius is merely wasted tokens. Drafts are auto because generating the 6-agent risk cards and a Markdown PRD in a local UI has harmed nobody and requires zero context switching. Writes are confirm because push_epic_to_jira() changes the shared engineering backlog. Sends are blocked because broadcasting feature priority to the wider company is irreversible.

## 06 Verification · AI Testing & Measurement

**The check before output ships**

The check that runs before output ships
Every generated PRD must cite at least three verifiable customer evidence points (Zendesk ticket IDs or Gong timestamps) that appear verbatim in the ingested documents. The Lead Engineer agent must also successfully validate the JSON schema of the output before rendering.

**Failure behaviour**

If the Synthesizer cannot find three verbatim quotes to support a feature, it stops drafting that section and outputs: "Insufficient customer evidence to proceed." It never invents a citation to pass the gate. Unverified drafts are surfaced with a visible warning badge, and the push_epic_to_jira() export button is explicitly disabled until the PM intervenes.
